# 帳號與審核機制子系統 C4 架構設計文件 (Account & Moderation C4 Model)

本文件基於實際開發完成之前端模組 (`user-center.html`, `profile-settings.html`, `identity-verification.html`, `blocked-users.html`, `report-user.html`, `notifications.html`, `hate-monitoring.html`)，採用 C4 模型（Context, Containers, Components, Code）進行全方位的系統架構對應與藍圖規劃。

---

## Level 1: System Context (系統上下文層)

描述帳號與審核機制子系統與終端使用者、審核人員及外部第三方服務之間的互動邊界。

* **系統參與者 (Actors)**：
  * **一般用戶 (End User)**：進行個人檔案設定、真人實名認證（KYC）、檢舉違規用戶、維護黑名單與查看系統/互動通知。
  * **審核管理員 (Moderator)**：透過後台審核實名認證申請、處理用戶檢舉單，並對違規帳號進行處置。
* **帳號與審核子系統 (Account & Moderation Subsystem)**：
  * 負責使用者個人檔案 CRUD、三步驟真人實名驗證流程、黑名單隔離、違規檢舉單建立與證明文件上傳、通知發送及 AI 仇恨值 (Hate Score) 監控。
* **外部依賴系統 (External Systems)**：
  * **第三方 KYC 認證服務**：處理證件 OCR 辨識與動態自拍比對。
  * **推播與 SMS SaaS**：發送驗證結果、違規處分提醒與系統例行維護通知。

## Level 2: Containers (容器層)

將帳號與審核機制拆解為獨立運作或可部署的技術容器：

1. **前端使用者介面容器 (Frontend SPA Client)**
   * **技術棧**：HTML5, CSS3 (`theme.css` 與對應模組 CSS)，Vanilla JS。
   * **包含頁面**：
     * `user-center.html`：帳號管理與安全功能的入口樞紐，展示實名驗證標章 (`.dp-badge-verified`) 與社群健康度預覽。
     * `profile-settings.html`：個人基本資料、職業類別、關於我、興趣標籤（限制最多 5 項）表單。
     * `identity-verification.html`：Step 1 基本身分、Step 2 證件正反面上傳、Step 3 鏡頭自拍動態比對。
     * `blocked-users.html`：黑名單清單渲染與動態解除封鎖管理。
     * `report-user.html`：檢舉對象下拉選擇（帶入頭像與對話時間）、違規分類、詳細描述與多張截圖上傳。
     * `notifications.html`：分類 Tab 切換（全部、未讀、系統、互動）、未讀點標記與「全部標為已讀」動作。
     * `hate-monitoring.html`：Hate Score 視覺化進度條 (`#gaugeFill`)、系統處罰紀錄與 AI 言語敏感度模擬測試器。
2. **個人檔案與身分服務 (Profile & Identity Service)**
   * **職責**：處理用戶屬性變更、興趣標籤邏輯校驗、KYC 認證狀態同步與黑名單 (Blacklist) 資料綁定。
3. **安全審查與檢舉服務 (Safety & Moderation Service)**
   * **職責**：管理檢舉單 (Report Ticket) 的建立與證明文件儲存、24 小時審核佇列處理，以及與第三方 KYC 服務介接。
4. **AI 風險評估服務 (AI Risk Assessment Service)**
   * **職責**：即時分析用戶對話語意、計算帳號 Hate Score (0-100)，並據此調整帳號風險狀態（良好、預警、凍結）。
5. **通知服務 (Notification Service)**
   * **職責**：管理系統通知與互動通知的發送、未讀數計數與一鍵已讀狀態更新。

## Level 3: Components (元件層)

對應前端各個 `.html` 頁面與內部業務邏輯元件：

* **1. 個人中心樞紐模組 (`user-center.html`)**
  * `UserCenterController`：整合用戶資訊標頭 (`.dp-profile-header`)、實名驗證徽章 (`.dp-badge-verified`)、社群健康度卡片 (`.dp-health-card`)、快速選單群組與 session 清理 / 登出處理 (`#logoutBtn`)。
* **2. 檔案編輯與驗證模組 (`profile-settings.html` / `identity-verification.html`)**
  * `ProfileSettingsComponent`：大頭照選擇與預覽 (`#avatarInput`)、顯示暱稱與職業 select 選擇器、興趣標籤 DOM 綁定與最多 5 項防呆控制 (`#tagContainer`)。
  * `IdentityVerificationComponent`：Step 1 姓名/身分證字號驗證、Step 2 證件正反面圖檔上傳與本地 preview (`#idFrontBox`, `#idBackBox`)、Step 3 鏡頭自拍觸發按鈕 (`#startSelfieBtn`)。
* **3. 社群安全與維護模組 (`blocked-users.html` / `report-user.html`)**
  * `BlockedUsersComponent`：渲染封鎖清單、非同步發送解除封鎖請求 (`.dp-btn-unblock`)，當清單為空時切換展示空狀態區塊 (`#emptyState`)。
  * `ReportUserComponent`：對話對象動態下拉選單 (`#reportedUserSelect`) 與預覽卡片切換、手動輸入 User ID 觸發器 (`#manualIdGroup`)、多圖檔截圖拖曳與預覽清單 (`#screenshotGrid`)。
* **4. 監控與訊息反饋模組 (`notifications.html` / `hate-monitoring.html`)**
  * `NotificationCenterComponent`：Tab 分類切換器 (`#notificationTabs`)、未讀紅點標記、一鍵已讀動作 (`#markAllReadBtn`)。
  * `HateMonitoringDashboard`：Hate Score 視覺化量表動態繪製 (`#gaugeFill`)、帳號權限狀態清單、AI 仇恨權重即時測試器 (`#analyzeBtn`)。

## Level 4: Code (程式碼層) - 以「檢舉單建立 (`report-user.html`)」與「AI 仇恨值模擬 (`hate-monitoring.html`)」為例

以下展示前端元件的 DOM 事件監聽與資料處理邏輯：

### 1. 檢舉對象動態切換與圖檔上傳控制器 (`report-user.js`)

```javascript
document.addEventListener('DOMContentLoaded', () => {
  const userSelect = document.getElementById('reportedUserSelect');
  const targetPreview = document.getElementById('targetPreview');
  const manualIdGroup = document.getElementById('manualIdGroup');
  const screenshotInput = document.getElementById('screenshotInput');
  const screenshotGrid = document.getElementById('screenshotGrid');

  // 對象選擇動態切換（帶入頭像與最近對話時間）
  userSelect.addEventListener('change', (e) => {
    const val = e.target.value;
    if (val === 'manual_search') {
      targetPreview.style.display = 'none';
      manualIdGroup.style.display = 'block';
    } else if (val) {
      const selectedOption = userSelect.options[userSelect.selectedIndex];
      document.getElementById('targetAvatar').src = selectedOption.dataset.avatar;
      document.getElementById('targetName').textContent = selectedOption.text.split('(')[0].trim();
      document.getElementById('targetDetail').textContent = `最近對話：${selectedOption.dataset.time}`;
      
      manualIdGroup.style.display = 'none';
      targetPreview.style.display = 'flex';
    } else {
      targetPreview.style.display = 'none';
      manualIdGroup.style.display = 'none';
    }
  });

  // 多張對話截圖預覽 (最多 3 張)
  screenshotInput.addEventListener('change', (e) => {
    const files = Array.from(e.target.files).slice(0, 3);
    screenshotGrid.innerHTML = '';
    
    files.forEach(file => {
      const reader = new FileReader();
      reader.onload = (event) => {
        const img = document.createElement('img');
        img.src = event.target.result;
        img.className = 'dp-screenshot-item';
        screenshotGrid.appendChild(img);
      };
      reader.readAsDataURL(file);
    });
  });
});
