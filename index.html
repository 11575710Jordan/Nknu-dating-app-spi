Nknu-dating-app-spi · 軟體流程改善研究

交友軟體 POC 頁面導覽

純前端原型（HTML + CSS + JS，不使用框架，無後端與資料庫）。已將登入 → 配對 → 傳訊息 → 個人中心的主要流程串起來，以下依功能分組列出所有頁面入口，點擊卡片即可開啟。

立即從登入開始體驗
測試帳號：u01@nknu-demo.app　密碼：demo1234（登入頁上也會顯示）。登入後會固定以配對頁的測試帳號 u01 陳彥廷進入，個人中心、配對頁會是同一個人。配對成功後按「傳送第一則訊息」會直接開啟訊息頁對應的對話。個人中心裡「更多功能」區塊是尚未開發的功能，點進去會先看到開發中的假 404 畫面。各頁資料存於瀏覽器 localStorage，清除資料即回到初始狀態。
