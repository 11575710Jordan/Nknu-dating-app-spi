# Nknu-dating-app-spi
軟體流程改善研究-交友軟體

---

## 配對頁（`pages/match.html`）

純前端 demo（HTML + CSS + JS，不使用框架），沒有後端與資料庫；模擬資料以 JS 檔載入，**直接用瀏覽器開啟 `pages/match.html` 即可使用**，不需要架伺服器。

### 檔案結構

| 檔案 | 用途 |
|---|---|
| `pages/match.html` | 配對頁 |
| `pages/match.css` | 配對頁樣式（只使用 `theme_guide/theme.css` 的變數與 `dp-` 元件，頁面 class 加 `match-` 前綴） |
| `pages/match.js` | 畫面邏輯：卡片、評分、篩選、寵物管理、點數 |
| `js/match-logic.js` | 不碰畫面的純邏輯（評分規則、篩選、驗證、點數），可單獨測試 |
| `data/mock-data.js` | 模擬後端資料：14 位用戶、12 隻寵物、預設評分 |
| `tests/match-logic.test.js` | 邏輯測試 |

### 測試帳號

頁面最上方可輸入帳號（`u01`～`u14` 或完整姓名），確定後以 `match.html?user=u01` 重新整理，用該帳號登入操作。

| 想展示的功能 | 建議帳號 |
|---|---|
| 一般配對、已有人給你加分 | `u01` 陳彥廷 |
| 女方評分（一人最多 60%，可單獨讓照片變清晰） | `u02` 林予晴 |
| 多隻寵物 | `u04` 黃維倫 |
| 長輩模式（65 歲以上自動進入） | `u11`～`u14` |
| 沒有寵物（寵物模式空狀態） | `u03` 許安琪 |

「重設」按鈕會清除瀏覽器中的評分、寵物異動與點數，回到模擬資料的初始狀態。

### 功能與規則

**配對模式**
- **一般**：所有用戶在同一個卡池，不限性別，可在篩選中指定。
- **寵物**：以自己的寵物身分和其他寵物配對。
- **長輩**：只有 65 歲以上用戶可使用（登入後預設進入），只顯示 65 歲以上的對象，介面字級與按鈕放大。

**評分（取代左右滑）**
- 關係分數滿分 100%，每按一次 +5 / -5，分數為 0 時只能加分。
- 分數上限：異性配對女方 60%、男方 40%；同性配對各 50%；寵物配對各 50%。
- 第一次加分可以留一句話給對方（只有這一次機會）。
- 雙方都加過分即配對成功。

**照片清晰度**
- 人的照片依關係分數（雙方加總）逐步變清楚：0% 時霧化但看得出輪廓，60% 以上完全清晰。
- 寵物照片不模糊。

**卡片**
- 預設收合，整頁剛好一個畫面高、不需捲動；點卡片空白處展開，顯示自我介紹、完整資料與動態。
- 支援多張照片，點照片左右兩側切換。

**篩選**
- 右上角篩選鈕開啟浮動面板，按「確定」才更新配對結果。
- 一般模式：性別、年齡、距離、學校、工作領域、興趣；長輩模式：性別、距離；寵物模式：種類、體型、個性。

**寵物管理**
- 寵物模式中可新增、編輯、刪除自己的寵物（品種、個性、外觀、介紹、最多 4 張照片）。
- 刪除寵物會一併刪除牠的評分紀錄。

**點數與動態**
- 每位對象（人或寵物）都有動態，花 30 點可永久解鎖。
- 點數取得：模擬課金方案（NT$30／100 點、NT$90／330 點、NT$150／600 點），或在點數面板手動輸入點數（任務系統之後由其他組員製作，目前以此模擬）。

### 資料儲存

評分、寵物異動、點數與解鎖紀錄存在瀏覽器的 `localStorage`（key：`nknu-match-demo-v3`），只存在該瀏覽器中，換瀏覽器或電腦不會同步。

### 執行測試

需要 Node.js 18 以上，不需安裝任何套件：

```bash
npm test
```

### 尚未完成／限制

- 「傳送第一則訊息」與其他頁面的連結尚未串接（目前連到 `#`）。
- 模擬資料中其他用戶不會主動回應評分，只有資料檔中預設的評分。
- 模擬資料的照片為佔位圖；在 `photos[].src` 填入圖片網址即可顯示真實照片。
- 新增的寵物沒有動態（動態只來自模擬資料）。
- 照片模糊為前端效果，正式上線時應由後端依分數提供不同清晰度的照片。

### 待提給主題負責人

- `theme.css` 的 base 樣式未對 `select` 設定 `font:inherit`，下拉選單字級會變小（本頁先在 `match.css` 補上）。
- 長輩模式的放大比例（125%）目前為頁面自訂值，主題尚無對應 token。
- `dp-action` 尚未定義停用（disabled）樣式，本頁自行補上。
