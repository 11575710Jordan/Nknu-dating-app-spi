# NKNU 交友專案

軟體流程改善研究的前端示範專案。從 `index.html` 進入，在同一瀏覽器內操作註冊、登入、配對、個人中心、聊天、共同行事曆、任務、集點、模擬課金與 AI 行程規劃。

## 啟動

使用編輯器的本機靜態伺服器，或在此資料夾執行 `py -m http.server 8080` 後開啟 `http://localhost:8080/`。也可用瀏覽器開啟 `index.html` 預覽畫面。完整流程應使用同一個 HTTP 網址，以便頁面共用瀏覽器儲存空間，並讓語音頁面請求麥克風權限。

測試帳號為 `u01@nknu-demo.app` 至 `u14@nknu-demo.app`，密碼皆為 `demo1234`。使用 Node.js 執行 `npm test` 可跑自動化測試。

## GitHub Pages

以整合分支的根目錄發布。首頁為 index.html，各頁以相對路徑載入資源，可在 GitHub Pages 的專案子路徑下執行。
