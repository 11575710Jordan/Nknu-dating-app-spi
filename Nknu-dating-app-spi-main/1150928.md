## 頁面架構總覽

```
├── pages/
│   ├── login.html                   # 1. 帳號登入頁面
│   ├── forgot-password.html         # 2. 忘記與重設密碼頁面
│   ├── user-center.html             # 3. 個人中心主頁 (控制台)
│   ├── profile-settings.html        # 4. 編輯個人資料 (含興趣標籤與大頭照)
│   ├── community-ethics.html        # 5. 社群禮儀與仇恨值監控
│   ├── identity-verification.html   # 6. 實名與真人驗證 (證件與自拍比對)
│   ├── blocked-users.html           # 7. 已封鎖用戶名單
│   └── report-user.html             # 8. 檢舉與申訴 (雙入口機制與舉證上傳)

```

## 模組功能詳細說明

### 1. 帳號登入頁面 (`login.html`)

* **主要功能**：使用者存取系統的入口，支援多元登入方式。

### 2. 忘記與重設密碼頁面 (`forgot-password.html`)

* **主要功能**：協助忘記密碼的使用者安全重設通行密碼。

### 3. 個人中心主頁 (`user-center.html`)

* **主要功能**：使用者個人資料、安全設定與社群狀態的核心控制台。

### 4. 編輯個人資料 (`profile-settings.html` / `profile-settings.js`)

* **主要功能**：讓使用者建立與維護吸引人的個人檔案，提升配對成功率。

### 5. 社群禮儀與仇恨值監控 (`community-ethics.html`)

* **主要功能**：維護平台良好的互動氛圍，視覺化呈現用戶的社群信用等級。

### 6. 實名與真人驗證 (`identity-verification.html`)

* **主要功能**：防止假帳號、機器人與詐騙，建立防護網。

### 7. 已封鎖用戶名單 (`blocked-users.html`)

* **主要功能**：管理使用者自主封鎖的對象，維護個人邊界。

### 8. 檢舉與申訴 (`report-user.html` / `report-user.js`)

* **主要功能**：通報違規行為與維護秩序的核心機制，支援彈性情境與舉證。
